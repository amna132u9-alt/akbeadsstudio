# AK Beads Studio

A static, single-page storefront for AK Beads Studio: premium beads, handmade jewelry and keychains. It is hosted on Netlify.

## Structure
- `public/index.html` is the whole site in one file, with inline CSS, JS and embedded images.
- `netlify.toml` publishes the `public/` folder. There is no build step.

## Run locally
Open `public/index.html` in a browser, or run `netlify dev`.
